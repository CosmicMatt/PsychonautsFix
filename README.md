# PsychonautsFix
A small DirectX hook to add a few QOL improvements to Psychonauts on PC.

Features Added/Atomatically Enabled:

  ### Controller
  - Adds Xinput support for wider controller options
  - Controller rumble reimplemented with Xinput support
  - Fixes endless spinning glitch on non X360 controllers
  - Patches button prompts to use Xbox button icons

  ### #Display
  - Borderless window
  - Fixed performance issues at high resolutions when Vsync was enabled
  - Resolution settings show aspect ratio next to each preset

Installation:
Simply drag and drop the DLL and ini file next to the game exe.

Made with SteamInput in mind so turn that on in steam. Should work on Steam Deck with the windows version running through Proton.
